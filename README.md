# LearnSphere

LearnSphere is a responsive learning dashboard built with React, Vite, Tailwind CSS, and React Icons. It provides a polished, production-style experience for exploring courses, searching content, tracking progress, and continuing learning journeys.

## Project Overview

This frontend-only application focuses on a modern SaaS-style experience with reusable components, a consistent visual system, responsive layouts, and static course data. The interface is designed to feel professional, minimal, and scalable for future expansion.

## Features

- Responsive navbar with a mobile drawer
- Hero section with a premium dashboard feel
- Four learning statistics cards
- Real-time course search
- Category-based course filtering
- Reusable course cards with progress bars and status badges
- Continue-learning section for in-progress courses
- Custom typography and Tailwind-powered styling

## Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- React Icons
- Google Fonts

## Folder Structure

- src/components: reusable UI sections
- src/data: static course content
- src/App.jsx: main app composition
- src/index.css: Tailwind and theme setup
